# Sandbox and evidence policy

- Inputs are read-only manifests under the external DocSem train directory plus the supplied Codex reference and recovered-query JSONL files.
- Generated outputs stay under `artifacts/ambiguity/`, the Issue 14 research report, schema, tests, and this mission/state directory.
- Automatic lexical matches are signals, not confirmed defects, unless a structural rule demonstrates incompatible operands, rates, or targets.
- Agent review is text-only. No source PDF visual review was performed.
- Neither automated screening nor agent review is described as completed human adjudication.
- The mission validator is deterministic, standard-library-only, and writes the completion artifact only after all assertions have been evaluated.
