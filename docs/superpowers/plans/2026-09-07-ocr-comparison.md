## Decision and boundaries

Compare Apple Vision accurate, the pinned RapidOCR ONNX configuration, and the pinned native Paddle PP-OCRv5 configuration on identical public PDF pixels. Prioritize accurate numerical inputs, relationship text and literal Evidence IDs; speed is a secondary capacity constraint. OCR metrics are proxies for final Joint Exact Accuracy, not estimates of private test scores.

Freeze a seeded representative sample before looking at engine results: 20 held-out documents and 10 train documents, two distinct content-blind SHA-sampled pages per document, excluding the two previous held-out pilot documents. Select documents in ascending SHA-256 order of `issue24-ocr-benchmark-v1:` plus instance ID. Select pages by SHA-256 of the frozen prefix, split, instance ID, PDF hash and page number. Preserve the initial first/last-page manifest as a superseded diagnostic and use the revised manifest for all scored runs. No queries, labels, old answers or portal feedback enter the comparison. Preserve source and render hashes, engine versions/settings, outputs, timings and errors.

Use independent image-only transcriptions as an explicitly silver reference. Reference readers cannot see candidate OCR, user queries, answers or each other's responses. Report agreement, disputed/unreadable regions, exclusion denominators and source coverage. Never call model consensus human gold. The final metric protocol is frozen before candidate score inspection. Three full-width non-overlapping horizontal cores use y bounds floor(height*k/3), k=0..3. Exclude and count lines crossing a core boundary; reference readers receive the full source page and the three exact core crops. Transcribe ordinary document text, including headings, without diagonal background watermarks; do not solve questions. Normalize NFC and whitespace only. Each metric has its own eligibility: exact consensus body transcript for CER/WER, exact consensus of deterministically derived heading-token multisets and numeric multisets for those metrics, with disagreement and unreadability reported. Candidate OCR lines are assigned using frozen geometry, not matches to whichever reference maximizes the score.

Compare lexical leading-heading tokens and numeric occurrences as region-scoped multisets. The shared heading parser is an Evidence-ID transcription proxy: other leading colon labels can qualify, so this metric is not semantic gold identification of evidence blocks. Both reference and candidate tokens come from the same parser over their line transcriptions; model-curated token arrays remain observations only. Report micro and page-macro precision/recall/F1, text CER/WER and eligible support, initialization and median/p95 warm time. Crashed or missing page outputs are empty hypotheses and count as failures. Numeric literals are derived from each reader transcript with the same frozen lexical parser used for every OCR candidate, excluding heading identifiers. The literal parser preserves leading decimals, signs, fractions and scientific exponents without numeric-value normalization. Two clear readers agreeing on an empty core keep that core eligible for body insertion errors. Model-provided ID and numeric arrays are retained only as raw observations, so a visible clock such as 15:00 cannot invalidate an otherwise valid transcript. The common parser tokenizes such a clock into 15 and 00 on both sides. Word-form quantities remain part of the text metric. Because competition rank is determined on Held-out, use the Held-out stratum for model selection and report Train separately as a transfer check; do not let easier Train typography determine the winner. Also report the pooled descriptive scores. Predeclare selection order: ID F1, numeric F1, CER/WER, failures and runtime. Use a fixed-seed paired bootstrap clustered by document within split for uncertainty. Point-estimate order is provisional. Paired intervals cover ID/numeric F1, CER/WER, failure rate and successful-page median latency. An interval spanning zero proves neither equality nor superiority; an unresolved comparison prompts further evidence or an explicit uncertainty statement. Report failed attempt time separately from successful-page latency. OCR proxy scores never become invented Joint Accuracy scores.
